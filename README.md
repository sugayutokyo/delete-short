# YouTube Shorts Blocker (ショート動画非表示 Chrome拡張機能)

YouTube上のすべてのショート動画（ホーム、登録チャンネル、検索結果、サイドバーナビゲーション、チャンネルタブなど）を非表示にするGoogle Chrome拡張機能です。
拡張機能のアイコンを**右クリック**して表示されるメニューから、いつでもワンクリックでON/OFFを切り替えることができます。

---

## 主な機能

1. **すべてのショート動画・ゲームルームを徹底非表示**
   - ホームフィード・登録チャンネルフィードのショート棚
   - 検索結果やフィード内に紛れ込む個別のショート動画
   - 左側サイドバー（ガイドメニュー・ミニガイド）の「Shorts / ショート」ボタン
   - チャンネルページの「ショート」タブ
   - 関連動画・おすすめ一覧のショート棚
   - **「ゲームルーム (Playables)」** のサイドバー項目・棚・フィード内アイテムおよび直接アクセス時のリダイレクト
2. **右クリックで手軽にON/OFF切り替え**
   - 拡張機能アイコンを右クリックすると `✓ ショート動画非表示: ON (クリックでOFF)` が表示され、クリックするだけで瞬時に切り替えられます。
   - ツールバー上のアイコンには現在の状態（`ON` / `OFF`）がバッジ表示されます。
   - アイコンの通常クリック（左クリック）でも同様にON/OFFがトグルします。
3. **通常動画プレイヤーへの自動リダイレクト**
   - 機能がONのとき、ショートのURL（`https://www.youtube.com/shorts/VIDEO_ID`）に直接アクセスした場合は、通常の動画プレイヤー（`https://www.youtube.com/watch?v=VIDEO_ID`）へ自動転送されます。縦型無限スクロールのショート画面に迷い込む心配がありません。
4. **超高速・チラツキ（FOUC）なし**
   - `document_start` でページ描画開始前に即座に非表示CSSを適用するため、読み込み時に一瞬だけショートが表示される不快なチラツキがありません。

---

## インストール手順 (Chromeへの読み込み)

1. **Google Chrome** を起動します。
2. アドレスバーに以下を入力してEnterキーを押します：
   ```text
   chrome://extensions/
   ```
3. 画面右上にある **「デベロッパー モード」** のトグルスイッチを **ON** にします。
4. 画面左上に出現する **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. フォルダ選択ダイアログで、このプロジェクトフォルダ（`delete-short`）を選択します：
   ```text
   /Users/trinity/Developer/private/delete-short
   ```
6. 拡張機能一覧に **「YouTube Shorts Blocker (ショート動画非表示)」** が追加されます。

> **Tips: アイコンの固定表示**
> Chromeツールバー右上にある「パズルピース」マーク（拡張機能アイコン）をクリックし、`YouTube Shorts Blocker` の横にある **ピン留めアイコン** をクリックすると、常にツールバーにアイコンが表示され、右クリックでの操作がしやすくなります。

---

## 使い方

1. **YouTube（`https://www.youtube.com/`）を開きます**。
2. ショート動画やショート棚、サイドバーのShorts項目がすべて綺麗に消えていることを確認できます。
3. **一時的にショート動画を見たい場合**:
   - ツールバーのアイコンを **右クリック** します。
   - `✓ ショート動画非表示: ON (クリックでOFF)` をクリックします。
   - バッジが `OFF` になり、ページをリロードすることなくショート動画が再表示されます。
   - 再度非表示にしたいときは、右クリックメニューまたはアイコンをクリックするだけで瞬時に `ON` に戻ります。

├── content.css         # ショート要素を網羅的に非表示にするCSS
├── content.js          # DOM制御・SPA画面遷移監視・リダイレクト処理
├── icons/              # アプリアイコン (16px, 32px, 48px, 128px)

│   ├── icon32.png
│   ├── icon48.png
│   └── icon128.png
└── README.md           # 本説明書
